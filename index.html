      Legenda do post

      Este navegador não deixou copiar sozinho. Selecione o texto e copie (Ctrl+C, ou segure o dedo no celular).

      Modelos salvos

      Para ter os mesmos modelos em outro computador: exporte aqui e use Importar arquivo lá. A importação junta os modelos; quando o mesmo cargo existe nos dois, fica o texto salvo por último.

      Chave da API do Claude

      Usada pelo botão Gerar com IA, que escreve Requisitos, Diferencial e Principais atividades a partir do cargo.

      Crie a chave em console.anthropic.com, no menu API Keys. O uso é cobrado na conta da Anthropic.

      A chave fica salva só neste navegador. Quem usar este computador pode vê-la. Não salve em computador compartilhado e use uma chave só para este app, com limite de gasto.
